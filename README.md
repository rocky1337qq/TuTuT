# Сервис посуточной аренды квартир «ТуТуТ» (Оренбург)

Курсовой проект: Веб-сервис аренды апартаментов с клиентской частью, REST API, JWT-аутентификацией, базой данных MySQL (7 связанных таблиц) и панелью администратора.

## Стек технологий

- **Фронтенд:** Чистый HTML5, CSS3, Vanilla JavaScript (без сторонних UI-фреймворков)
- **Бэкенд:** Node.js, Express.js
- **База данных:** MySQL / MariaDB (через XAMPP, чистый SQL с помощью `mysql2` без ORM)
- **Безопасность:** JWT (JSON Web Tokens), хэширование паролей с `bcryptjs`, защита от XSS и SQL Injection (параметризованные запросы)

---

## Схема базы данных (7 таблиц)

1. `users` — пользователи системы с разграничением ролей (`user` и `admin`), хэшированными паролями и контактными данными.
2. `apartments` — каталог квартир с характеристиками (комнаты, площадь, этаж, описание, реальные координаты в Оренбурге, цена за сутки).
3. `photos` — фотографии квартир (связь `1:N` к `apartments`).
4. `amenities` — справочник удобств (Wi-Fi, кондиционер, парковка, кухня и т.д.).
5. `apartment_amenities` — связь `M:N` между квартирами и удобствами.
6. `bookings` — заявки на бронирование с привязкой к пользователю и квартире, датами заезда/выезда, итоговой суммой и статусом (`pending`, `confirmed`, `cancelled`).
7. `reviews` — отзывы и оценки гостей (1–5 звёзд) с привязкой к пользователю и квартире.

## Запуск проекта

### 1. Требования
- Установленный [Node.js](https://nodejs.org/) (версия 18+)
- Запущенный MySQL в XAMPP Control Panel (порт 3306, пользователь `root`, без пароля)

### 2. Установка зависимостей
```bash
npm install
```

### 3. Инициализация базы данных
Скрипт автоматически создаёт базу данных `tutut`, все 7 таблиц со связями и заполняет их начальными тестовыми данными (10 реальных квартир в Оренбурге, тестовые отзывы и бронирования):
```bash
npm run init-db
```

### 4. Запуск сервера
```bash
npm start
```
Сервер будет доступен по адресу: **http://localhost:3000**

## Панель администратора (`/admin.html`)
- **Статистика:** Общее число квартир, пользователей, бронирований и общая выручка.
- **Квартиры:** Полный CRUD — добавление новой квартиры с фото и удобствами, редактирование цен, описаний, удаление.
- **Бронирования:** Управление заявками гостей, подтверждение и отмена броней.
- **Пользователи:** Просмотр списка пользователей, назначение роли `admin` или `user`.
- **Отзывы:** Модерация и удаление неприемлемых отзывов.
